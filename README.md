# Bridget Jones Diary

A personal online diary application inspired by the idea of having a private space to document everyday thoughts, experiences and memories.
Users can create diary entries, organise them into categories, revisit previous notes, edit existing entries and delete entries.

## Main Features
- Create diary entries: Write new notes with a title, category and content.
- View previous entries: Browse previously saved diary notes.
- Edit entries: Update the title, category and content of existing notes.
- Delete entries: Remove diary entries when they are no longer needed.
- Automatic timestamps: Each entry is automatically assigned a date and time when created.
- Latest entries first: Diary notes are displayed in chronological order, with the newest entries appearing first.
- Category organisation: Organise entries into Personal, Family, Friends, Memories, Thoughts and Other.
- Responsive design: A simple, accessible interface designed using Bootstrap and custom CSS.

## Technologies Used

Frontend:
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

Backend:
- Node.js
- Express.js
- PostgreSQL (SupaBase)
- REST API

## CRUD Operations

The application implements full CRUD (Create, Read, Update and Delete) functionality, allowing users to manage their diary entries.
